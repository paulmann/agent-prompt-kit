# Code of conduct

## Commitment

This project adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The text at that link is part of this document.

In our own words:

- discuss the instruction, not the person who wrote it;
- a criticism carries a verifiable fact: a module, a line, a scenario where the rule produces damage;
- "this prompt is bad" is not a finding; "M6 rule 5 lets an agent echo a token when it quotes a log"
  is;
- harassment, insults and publishing someone else's personal data are not acceptable.

## Scope

Issues, pull requests, discussions, the wiki, and anywhere a person acts on behalf of the project.

## Reporting

Privately, through the owner's profile or the **Report abuse** control. Reports are handled
confidentially.

## Consequences

A warning, then restricted participation, then a ban. The maintainer decides and states the reason
privately.
