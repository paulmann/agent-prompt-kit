# Адаптация: новый домен за пятнадцать минут

Промпт не знает ни одного домена, поэтому добавление домена — ограниченная процедура. Если она
занимает больше, промпт правят там, где его надо конфигурировать.

## Процедура

### 1. Написать карточку домена (10 минут)

Скопируйте шаблон из M2 файла `PROMPT.ru.md`. Заполняйте по материалу, который действительно есть:

| Поле | Признак хорошей записи |
|---|---|
| Практик | должность, на которую можно нанять |
| Словарь | 5–9 терминов; если не определяется в строку — знаете недостаточно |
| Набор навыков | 3–6; каждый применяется задачей, а не доменом вообще |
| Проверить | факты, которые неловко утверждать по памяти |
| Источники истины | файлы, схемы, стандарты, документация API — названы, не описаны |
| Типичный провал | как эта работа обычно ломается |
| Готово, когда | одно предложение, проверяемое ревьюером без вопросов к вам |
| Анти-паттерны | что здесь делает новичок, а старший — нет |

### 2. Добавить один проработанный пример (5 минут)

Положите в `examples/` той же формы, что три существующих: обычный случай или неоднозначный, если
обычный уже есть. Включите карточки, сжатый ответ с метками и строку ворот.

### 3. Написать строку приёмки

Одно предложение: что должно наблюдаться, чтобы работу приняли. Не «код чистый» — это ненаблюдаемо.
«Эндпоинт отдаёт поле, прежние тесты проходят» — наблюдаемо.

### 4. Версионировать

Добавьте запись в `CHANGELOG.md` с датой. Специализированного агента без версии нельзя аудировать:
следующий читатель не узнает, какое поведение проверялось.

### 5. Заложить в хранилище один рецепт

Домен с пустым хранилищем нечего достать при первом повторе. После первой успешной задачи в новом
домене напишите один рецепт по `skills/experience-reuse/templates/recipe.ru.md` и проверьте его:

```bash
python tools/experience.py add drafts/first-recipe.md
python tools/experience.py search "следующая задача вашими словами"
```

Вторая команда — и есть настоящая проверка приёмки: если поиск не выдаёт рецепт на запрос, написанный
так, как его напишет будущий проситель, — неверны заголовок и применимость записи, а не инструмент.

## Что менять нельзя

| Инвариант | Почему должен выжить |
|---|---|
| Порядок поглощения M3 | иначе приоритет станет тем, что агенту удобнее |
| Три метки M4 | убрать одну — две другие схлопнутся под давлением |
| Правила безопасности M6 | домен никогда не оправдывает обход секретов и необратимых действий |
| Ворота M8 | без них «готово» — мнение |
| Очистка и применимость M13 | доменное хранилище, пропускающее шесть вопросов, превращает переиспользование в слепое копирование |

Если домен как будто требует изменить один из них, честный ответ обычно такой: это другая задача —
переформулируйте карточку задачи.

## Признаки, что адаптация пошла не туда

| Симптом | Диагноз | Исправление |
|---|---|---|
| Промпт вырос на страницу ради одного домена | домен записали в промпт | перенести в карточку домена |
| Две карточки расходятся в «готово» | приёмку скопировали, а не вывели | написать одну строку приёмки, вторую удалить |
| Примерам нужны разные формы ответа | контракт вывода слишком жёсткий | оставить пять разделов M7, менять только их содержание |
| Каждая задача в домене «особая» | карточка слишком широкая | разделить домен, по карточке на каждый |
| Поиск всегда возвращает пусто | записи используют словарь хранилища, а не просителя | переписать заголовки и применимость словами будущего запроса |

## Микро-пример

```text
КАРТОЧКА ДОМЕНА — ревью миграций базы
Практик:            инженер надёжности баз данных
Словарь:            аддитивная миграция, окно блокировок, бэкфилл, путь отката, online DDL
Набор навыков:       чтение планов запросов; оценка времени блокировки; обратимые миграции
Проверить:          размер таблицы; аддитивно ли изменение; окно развёртывания
Источники истины:   миграции схемы, статистика таблиц, календарь развёртываний
Типичный провал:    NOT NULL без значения по умолчанию — таблица блокируется
Готово, когда:      миграция применяется и откатывается на копии, время блокировки измерено и названо
Анти-паттерны:      тест на пустой базе; «локально прошло» как свидетельство
```

Это вся адаптация: восемь полей, одно предложение приёмки, одна строка в журнале.
