# agent-prompt-kit

Переносимый системный промпт, который делает агента специалистом в той теме, что стоит перед ним,
— и, когда тот же класс работы повторяется, оставляет после себя рабочее окружение, из которого
следующая сессия стартует вместо нуля.

Четырнадцать модулей, десять инвариантов, ворота из двенадцати проверок, которые сообщаются одной
строкой. Имён инструментов внутри нет: каждая возможность определяется самим рантаймом (M6), поэтому
один и тот же текст работает в AutoClaw2, HARNESS, SagaAI и в любом агенте, который умеет читать
файлы и выполнять команды.

## Проблема, ради которой это существует

Хорошо сделанная один раз работа обычно оплачивается дважды. Следующее окно не знает, что
пробовали, какие имена колонок оказались настоящими, какая команда доказала результат, — поэтому
аналогичная задача стоит того же времени, тех же токенов и тех же ошибок, что и первая.

Ответ здесь не «стараться запомнить лучше». Ответ — артефакт: каталог с правилами, карточка домена,
критерий приёмки, разобранные примеры и хранилище прошлых работ, зарегистрированный в рантайме так,
чтобы следующая сессия действительно его видела. Механика и границы — на странице
[Зачем](00-Why.ru.md).

## Два выхода

| Выход | Когда | Где живёт |
|---|---|---|
| ответ | любая задача | в текущем диалоге |
| окружение специалиста | работа сделана и повторится | каталог, который рантайм регистрирует, названный путём |

## Проверить за две команды

```bash
git clone https://github.com/paulmann/agent-prompt-kit.git
cd agent-prompt-kit
python tools/prompt_lint.py          # PASS: 0 error(s), 0 warning(s)
python tools/experience.py selftest  # 13/13 experience checks passed
```

Обе возвращают `0` на свежем клоне: первая проверяет документ, вторая — что хранилище действительно
отклоняет то, что обещает отклонять. Что именно линтер считает ошибкой, перечислено в
[QA.md](https://github.com/paulmann/agent-prompt-kit/blob/main/docs/QA.md).

## Чем это не является

- **Не продукт памяти.** В хранилище лежат написанные вами Markdown-записи, а не эмбеддинги ваших
  диалогов.
- **Не промпт под одну предметную область.** Домен никогда не попадает в тело промпта: он живёт в
  карточке домена (M2) и в окружении (M10). Тело промпта не меняется, когда вы добавляете
  специальность.
- **Не гарантия.** Ворота прогоняет агент, а читает человек. Строка ворот, которые никто не
  прогонял, — первый режим отказа, который называет сам набор (M9).
- **Не установлено, пока рантайм об этом не знает.** Файлы на диске — ещё не окружение
  (M10, шаг 4).
