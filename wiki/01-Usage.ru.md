# Использование

## Загрузить промпт

1. Откройте `PROMPT.ru.md`.
2. Скопируйте всё ниже YAML-заголовка в поле системного промпта агента.
3. Сохраняйте идентификаторы модулей: на них ссылаются ревью, документация и линтер.

Больше ничего не нужно. Промпт не называет инструментов, поэтому работает в любом рантайме, умеющем
читать файлы и выполнять команды; отсутствующие возможности деградируют явно (M6).

## Проверить набор до доверия

```bash
python tools/prompt_lint.py          # код 0 = документ структурно полон
python tools/prompt_lint.py --json   # машинный вывод находок
```

## Как выглядит верный ответ

```text
## Ответ
<результат>

## Свидетельства
- утверждение — путь:строка / URL / вывод команды

## Предположения
- предположение — последствие, если неверно

## Открытые вопросы
- что определить не удалось и почему это важно

## Следующий шаг
<одно действие с командой>

ворота 11/11
```

Три проработанных версии в трёх несвязанных доменах — в `examples/EXAMPLES.ru.md`.

## Первые пять минут с новой темой

1. Дайте агенту написать карточку задачи. Если он не может назвать тему одним предложением, он не
   понял запрос.
2. Дайте написать карточку домена. Если набор навыков подходит любому проекту — он универсален и
   бесполезен; спросите конкретно про «что проверить».
3. Прочитайте строку ворот. Отсутствие строки означает, что ворота пропущены.
4. Только потом читайте результат.
