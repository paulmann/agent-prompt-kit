# Установка

Один установщик, три рантайма и одно честное правило: шаг, который может сделать только человек,
написан как шаг человека.

```bash
git clone https://github.com/paulmann/agent-prompt-kit.git
cd agent-prompt-kit
python tools/install.py --runtime autoclaw2 --check
python tools/install.py --runtime autoclaw2 --write
```

| Рантайм | Команда | Модель делает | Человек делает |
|---|---|---|---|
| AutoClaw2 | `/agent-prompt-kit` | пишет навык и файл команды в профиль | перезагружает, чтобы снимок ресурсов пересобрался |
| HARNESS | `/agent-prompt-kit` | создаёт весь каталог Workspace | один клик: добавить каталог как Workspace |
| SagaAI | — | вставляет `PROMPT.ru.md` как рабочий контракт | по требованиям рантайма |

`--check` ничего не пишет и сообщает состояние регистрации, а не только файлы. В HARNESS клик
остаётся открытым после успешной установки; в AutoClaw2 отчёт остаётся `NOT READY`, пока записи нет в
манифесте ресурсов.

Полная механика, замеренные пути и таблица ловушек: `docs/INSTALL.ru.md` в репозитории.
