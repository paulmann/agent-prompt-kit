# Установка

Один установщик, три рантайма и одно честное правило: шаг, который может сделать только человек,
записан как шаг человека, а не как «агент сделал».

```bash
git clone https://github.com/paulmann/agent-prompt-kit.git
cd agent-prompt-kit
python tools/install.py --runtime autoclaw2 --check    # ничего не пишет, сообщает состояние
python tools/install.py --runtime autoclaw2 --write    # ставит навык и команду
```

Зависимостей, кроме стандартной библиотеки Python, нет.

## Что делают два вызова

| Вызов | Действие |
|---|---|
| `--check` | осматривает каталог навыка, файл команды и манифест ресурсов рантайма; печатает ревизию, число навыков и команд, разрешённые пути и вердикт |
| `--write` | копирует навык и записывает файл команды, сохраняя заменяемое в резервную копию |
| `--runtime harness` | создаёт каталог workspace для HARNESS вместо профиля AutoClaw2 |
| `--runtime sagai` | **отказывается**: путь регистрации не измерен, и установщик не угадывает |

Вердикт `READY` означает, что файлы есть **и** манифест их содержит. Важна вторая половина: файл, не
попавший в ревизию ресурсов, для модели невидим.

## По рантаймам

| Рантайм | Команда | Что делает модель | Что делает человек |
|---|---|---|---|
| AutoClaw2 | `/agent-prompt-kit` | пишет каталог навыка и файл команды в профиль | перезагружает, чтобы снимок ресурсов пересобрался |
| HARNESS | `/agent-prompt-kit` | создаёт весь каталог workspace с файлами | один клик: добавить каталог как workspace |
| SagaAI | — | вставляет тело `PROMPT.ru.md` как рабочий договор | то, что требует этот рантайм |

Две замеренные детали, обе легко упустить:

- **Снимок ресурсов фиксируется на старте сессии.** После `--write` команда появится в палитре только
  в новой сессии (или после перезагрузки). В сессии, где вы установили, её нет — это не провал
  установки.
- **Клик в HARNESS остаётся открытым после успешной установки.** Установщик может создать каталог;
  зарегистрировать его может только приложение. То же с сохранённым агентом: агент, существующий как
  файлы и не зарегистрированный, — не окружение (M10, шаг 4; проверка 12 ворот).

## Проверка после установки

```bash
python tools/install.py --runtime autoclaw2 --check    # ожидается READY (autoclaw2)
```

Затем в **новой** сессии:

1. команда `/agent-prompt-kit` есть в списке;
2. просьба «напиши карточку задачи для этого запроса» выдаёт карточку, а не описание карточек;
3. ответ на любую небольшую задачу заканчивается строкой ворот.

Если третий пункт не выполняется, установка в порядке, а промпт не загружен. Исправлять нужно второе,
а не первое.

## Ловушки

| Ловушка | Симптом | Действие |
|---|---|---|
| установка в не тот профиль | `--check` говорит `READY`, команды нет | посмотреть разрешённый каталог навыка, который печатает `--check` |
| ожидание команды в той же сессии | палитра не изменилась сразу после `--write` | начать новую сессию |
| `--write` принят за регистрацию | файлы есть, ничего не видно | `--check` должен сказать `READY`, а не просто «записано» |
| установка для второго рантайма вручную | две расходящиеся копии навыка | запустить установщик для этого рантайма и отдать файлы ему |
| правка установленного навыка руками | репозиторий и профиль расходятся молча | править репозиторий, переустановить, перепроверить |
| предположение, что SagaAI устроен как остальные | каталог появился, регистрации нет | вставить промпт в поле системного промпта как договор |

## Удаление

Удалите каталог навыка и файл команды, которые назвал `--check`, затем перезагрузите. Больше на машине
ничего не затрагивается: установщик пишет только в выбранный профиль рантайма.
