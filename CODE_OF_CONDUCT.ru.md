# Кодекс поведения

## Обязательство

Проект принимает [Contributor Covenant версии 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
как свой кодекс поведения. Текст по ссылке — часть этого документа.

Своими словами:

- обсуждается инструкция, а не человек, который её написал;
- критика несёт проверяемый факт: модуль, строку, сценарий, где правило даёт ущерб;
- «промпт плохой» — не находка; «M6 п.5 позволяет агенту повторить токен, когда он цитирует лог» —
  находка;
- преследование, оскорбления и публикация чужих персональных данных недопустимы.

## Область

Issues, pull request, discussions, вики и любое место, где человек выступает от имени проекта.

## Как сообщить

Приватно — через профиль владельца или кнопку **Report abuse**. Сообщения рассматриваются
конфиденциально.

## Последствия

Предупреждение, затем ограничение участия, затем блокировка. Решение принимает сопровождающий и
сообщает причину приватно.

## Атрибуция

Contributor Covenant 2.1 распространяется по CC BY 4.0 и принадлежит его авторам. Этот файл объявляет
принятие и указывает канал сообщения.
